# Website design rating rubric (above-the-fold desktop screenshot, 1366px wide)
Benchmark: https://www.gyanitylearning.com/ = 8/10 (modern hero, clear headline, strong CTA, good typography, consistent brand colours, polished imagery).

- 1 = broken / blank / error page / under construction
- 2 = very outdated (2000s look: table layouts, tiny text, clip-art, marquee, default fonts, cramped/garish), or clearly broken layout
- 3 = dated or amateur: cheap template, cluttered, poor hierarchy, weak/absent CTA, low-res or stretched images, clashing colours, inconsistent fonts, walls of text, sliders of banners with baked-in text
- 4 = below average: functional but generic/old template (e.g. 2015-era WordPress/Wix theme), uninspiring hero, weak branding, misaligned spacing; clearly would benefit from a redesign
- 5-6 = acceptable modern template, decent but generic
- 7-8 = modern, clean, professional (Gyanity level)
- 9-10 = excellent, agency-grade

keep = false when: parked domain / for sale / hosting default page / error page / not an education business / it's a directory or listing portal / it is obviously a large national brand or chain / a cookie or popup completely covers the page so you cannot judge (then also note "popup").
